# 承認待ちフローの次の改修（引き継ぎメモ）

- 作成: 2026-10-23 / 発端: ウィジェット（`hermes-widget`）向けに追加したディープリンク（commit `029e6fe`）
- 状態: **提案のみ**。実装はこのリポジトリ（hermes-mobile-pwa）で行う
- 前提: `npm run verify`（テスト82 + check:pwa 30項目 + build）を通すこと

## 0. 追加済みの契約（壊さない）

> 正本は `docs/DEEPLINK.md`。以下の表はその要約。

| 形式 | 例 | 挙動 |
|---|---|---|
| クエリ | `?open=inbox&task=<id>&board=<slug>` | タスクタブ＋承認待ちシート。`task` は先頭に寄せてヒント表示 |
| クエリ | `?open=chat` | チャットタブ |
| ハッシュ | `#inbox` / `#inbox:<task>` | 同一ドキュメント遷移でも拾える（`hashchange` 監視） |
| パス | `/inbox` / `/chat` | 予備（※bridge の公開パス許可が必要。現状は 401 になる） |
| 無視してよいパラメータ | `_=<epoch ms>` | キャッシュバスター。解釈しないが**消さない**こと |

読み取り後、`open` / `task` / `board` は `history.replaceState` で消している（リロードで開き直さないため）。

## 1. すぐ効く改善（低コスト）

### (a) 「回答済み」を PWA でも区別する
`/api/inbox` の `items[].lastComment` は `{author, body, at}` を返す。`author === 'mobile'` かつ
`at >= blockedAt` なら**自分が回答済み**。ウィジェットは既にこの判定で「未回答のみカウント」している。
PWA 側も:
- 回答済みは「回答済み（再開待ち）」バッジを付け、**未回答を上に／回答済みは折りたたむ**
- ヘッダ件数は未回答のみ（例: `承認待ち 2（回答済み 3）`）

### (b) シートを履歴に載せる（戻るで閉じる）
現状シートは `useState` のみで、Android の戻るはアプリ終了になる。`#inbox`（タスク指定時は `#inbox:<id>`）を
`history.pushState` で積み、`popstate`/`hashchange` で開閉を同期する。ディープリンクの受け口と実装が一本化される。

### (c) ディープリンク契約を1枚に固定
このファイルを正とし、外部（ウィジェット、Discord bot、将来のクライアント）はここを見る。
`?open=` の値追加は後方互換で行う。

## 2. 中コスト（価値は高いが bridge 変更を伴う）

### (d) 「再開（unblock）」をシートから実行
- 現状: コメント投稿のみでステータスは変えない（再開は Discord / ダッシュボード）
- 提案: 回答後に「再開する」を出し、確認1タップで unblock。
- 必要: bridge に `POST /api/boards/:slug/tasks/:id/unblock`（`kanban.abort` と同型、`writeAllowed` + `auth.audit`）。
  **注意**: これは「エージェントを動かす」操作なので、誤タップ防止（確認ダイアログ + 監査ログ）を必須にする。

### (e) 通知からの復帰導線
- Web Push は使えない（tailnet 限定・push サービス無し）。**閉じている時の気づきはウィジェットアプリの
  WorkManager 通知が担う**（15分・新規のみ・24h dedupe）。
- PWA 側は「通知から開かれた」ことを前提に、`?open=inbox&task=` を受けたら
  1) シートを開く 2) 該当タスクを先頭 3) 回答欄にフォーカス、までやると体験が揃う（現状 1–2 は実装済み）。

## 3. やらない方がよいこと

- 承認待ちの自動承認・定型文の自動送信（事故の元）
- シート内でのステータス一括変更（監査が曖昧になる）
- `/inbox` パス公開のための bridge 改修（クエリ/ハッシュで足りている）

## 4. 推奨順序

1. (a) 回答済みの区別 — 表示だけ、テスト影響小
2. (b) シートの履歴化 — 戻る操作の改善＋ディープリンク実装の一本化
3. (c) 契約の固定 — ドキュメントのみ
4. (d) unblock 実行 — bridge 追加。やるなら監査ログと確認 UI をセットで
